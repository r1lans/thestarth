# Настройка админ-панели TheStarth (Google Sheets backend)

Без этого админ-панель откроется, но ничего не сохранит — сначала нужно
создать таблицу и подключить её. Это займёт 10–15 минут, один раз.

## Шаг 1 — создайте Google Таблицу

1. Откройте sheets.google.com → «Создать таблицу».
2. Назовите её, например, `TheStarth CMS`.
3. Создайте 3 листа (вкладки внизу) с ТОЧНО такими названиями и колонками
   в первой строке:

**Settings**
| key | value |
|---|---|
| accent_color | #1B6E4E |
| logo_image_url | |
| announcement_active | FALSE |
| announcement_text | |
| announcement_link | |

**News**
| id | title | body | date | published |
|---|---|---|---|---|

**Reviews**
| id | name | rating | text | date | published |
|---|---|---|---|---|---|

(Оставьте эти таблицы пустыми, кроме заголовков и строк Settings выше —
админ-панель дальше будет добавлять строки сама.)

## Шаг 2 — вставьте код

1. В таблице: Extensions → Apps Script (Расширения → Apps Script).
2. Удалите содержимое файла `Code.gs` по умолчанию и вставьте туда весь
   код из файла `Code.gs`, который я прислал рядом с этой инструкцией.
3. Сохраните (значок дискеты).

## Шаг 3 — задайте пароль администратора

1. В редакторе Apps Script: значок шестерёнки (Project Settings) слева.
2. Прокрутите до «Script Properties» → «Add script property».
3. Property: `ADMIN_TOKEN`. Value: придумайте длинный случайный пароль
   (например, сгенерируйте на randompassword.com) — это и есть пароль
   входа в админ-панель. Никому кроме админов его не давайте.

## Шаг 4 — опубликуйте как веб-приложение

1. В редакторе Apps Script: кнопка «Deploy» → «New deployment».
2. Тип (шестерёнка слева от «Select type») → «Web app».
3. Execute as: **Me** (ваш аккаунт).
4. Who has access: **Anyone**.
5. Deploy → разрешите доступ (Google спросит подтверждение — это ваш
   собственный скрипт, это нормально).
6. Скопируйте появившийся **Web app URL** — он заканчивается на `/exec`.

## Шаг 5 — впишите URL в сайт

1. Откройте `app.js`, найдите строку `const CMS_API_URL = "";` в самом
   начале файла и вставьте туда скопированный URL.
2. Откройте `admin.html`, найдите такую же строку и вставьте туда же.
3. Пересохраните файлы на хостинге.

## Готово

Теперь на `admin.html` при входе нужно ввести пароль из Шага 3 — и можно
публиковать новости, отзывы, менять цвет акцента сайта, логотип и баннер
объявлений. Изменения появятся на сайте у всех посетителей (сайт
подгружает эти данные при каждом открытии страницы).

### Важно про безопасность
Пароль проверяется на стороне Google (в самом скрипте), а не в браузере —
это настоящая защита, а не просто «спрятанная» кнопка. Но это
однопользовательский пароль без личных логинов для разных админов и без
журнала действий — для маленькой команды (1–3 человека) этого достаточно,
но это не замена полноценной системе с ролями, если админов станет много.

### Если что-то не работает
- Проверьте, что в Deploy → Manage deployments выбран **тип "Web app"**,
  а не "API executable".
- Все названия листов и колонок должны совпадать один в один — заглавные
  буквы важны.
- После любого изменения кода в Apps Script нужно сделать **New
  deployment** заново (или Manage deployments → Edit → Deploy), иначе
  сайт будет видеть старую версию скрипта.
