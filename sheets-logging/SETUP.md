# Настройка Google Sheets — заявки на оплату и регистрации

**Важно:** новости, отзывы, настройки сайта и аккаунты учеников теперь
живут в Firebase — см. `firebase-backend/FIREBASE_SETUP.md`, это
отдельная (и обязательная) настройка. Google Таблицы, описанные здесь,
нужны только для одной вещи: чтобы куратор/бухгалтер видел **новые
регистрации** и **заявки на оплату** в привычной таблице, без входа в
Firebase.

Это отдельная, самостоятельная настройка. Займёт 10 минут.

## Шаг 1 — создайте Google Таблицу

1. Откройте sheets.google.com → «Создать таблицу».
2. Назовите её, например, `TheStarth — Заявки`.
3. Создайте 3 листа (вкладки внизу) с ТОЧНО такими названиями и колонками
   в первой строке:

**Signups**
| date | name | phone | nickname | course | email |
|---|---|---|---|---|---|

**Payments**
| date | order_id | name | phone | course | amount | method | status |
|---|---|---|---|---|---|---|---|

**Contacts**
| date | name | phone | message |
|---|---|---|---|

(`Contacts` заполняется формой «Остались вопросы?» на главной странице
— для тех, кто пока не готов регистрироваться, но хочет спросить.)

(Оставьте таблицы пустыми, кроме заголовков — сайт будет добавлять
строки сам: `Signups` заполняется при регистрации нового ученика,
`Payments` — при отправке заявки на оплату.)

## Шаг 2 — вставьте код

1. В таблице: Extensions → Apps Script (Расширения → Apps Script).
2. Удалите содержимое файла `Code.gs` по умолчанию и вставьте туда весь
   код из файла `Code.gs`, который я прислал рядом с этой инструкцией.
3. Сохраните (значок дискеты).

## Шаг 3 — опубликуйте как веб-приложение

1. В редакторе Apps Script: кнопка «Deploy» → «New deployment».
2. Тип (шестерёнка слева от «Select type») → «Web app».
3. Execute as: **Me** (ваш аккаунт).
4. Who has access: **Anyone**.
5. Deploy → разрешите доступ (Google спросит подтверждение — это ваш
   собственный скрипт, это нормально).
6. Скопируйте появившийся **Web app URL** — он заканчивается на `/exec`.

## Шаг 4 — впишите URL в сайт

Впишите скопированный URL в переменную `SHEETS_LOG_URL` в двух местах:
1. `app.js` — в самом начале файла (используется для логирования
   регистраций).
2. `payment.html` — та же переменная `SHEETS_LOG_URL` (используется
   для логирования заявок на оплату).

## Готово

Теперь при каждой регистрации на сайте строка появится во вкладке
`Signups`, а при каждой заявке на оплату — во вкладке `Payments`.

### Если что-то не работает
- Проверьте, что в Deploy → Manage deployments выбран **тип "Web app"**,
  а не "API executable".
- Названия листов и колонок должны совпадать один в один.
- После любого изменения кода в Apps Script нужно сделать **New
  deployment** заново, иначе сайт будет видеть старую версию скрипта.
