# Настройка Firebase (аккаунты учеников + база данных сайта)

Один раз, минут 15-20. После этого сайт сам подключится.

## Шаг 1 — создайте проект

1. Откройте console.firebase.google.com → «Add project» / «Добавить проект».
2. Назовите его, например, `thestarth`. Google Analytics можно отключить
   (не нужен для наших задач).

## Шаг 2 — включите вход по email/паролю

1. В меню слева: Build → Authentication → Get started.
2. Вкладка «Sign-in method» → «Email/Password» → включить (Enable) → Save.

## Шаг 3 — создайте базу данных

1. В меню слева: Build → Firestore Database → Create database.
2. Выберите «Start in production mode» (это важно для безопасности).
3. Регион — любой ближайший (например Europe-west, Asia-south).

## Шаг 4 — настройте правила доступа

1. В Firestore Database → вкладка «Rules».
2. Замените всё содержимое на файл `firestore.rules`, который я прислал
   рядом с этой инструкцией → Publish.

Эти правила уже настроены так, что:
- каждый ученик видит и редактирует только свой профиль
- новости/отзывы читают все, но пишет только админ
- настройки сайта редактирует только админ

## Шаг 5 — получите конфигурацию для сайта

1. Шестерёнка рядом с «Project Overview» → Project settings.
2. Внизу вкладки «General» → «Your apps» → иконка `</>` (Web).
3. Назовите приложение (например `thestarth-web`) → Register app.
4. Появится блок кода `const firebaseConfig = {...}` — скопируйте только
   этот объект.
5. Откройте файл `firebase-config.js` в проекте сайта и вставьте
   скопированные значения вместо пустых строк.

## Шаг 6 — назначьте себя админом

Это делается только ПОСЛЕ того, как вы хотя бы раз зарегистрируетесь на
самом сайте через обычную форму (кнопка «Войти» → «Регистрация»).

1. Зарегистрируйтесь на сайте своим email.
2. В консоли Firebase: Authentication → Users → найдите свой email →
   скопируйте его **User UID** (длинная строка справа).
3. Firestore Database → Data → «Start collection» → имя коллекции:
   `admins`.
4. Document ID: вставьте скопированный UID. Добавьте любое поле,
   например `role` (string) = `admin` → Save.
5. Теперь при входе в `admin.html` под этим аккаунтом откроется панель
   администратора.

Чтобы добавить второго админа — повторите шаги 2-4 для другого аккаунта.

## Готово

Больше ничего вручную создавать не нужно — коллекции `users`, `news`,
`reviews`, `nicknames`, `settings` сайт создаст сам при первом
использовании.

### Важно
- `firebaseConfig` (Шаг 5) — это НЕ секретный ключ, его можно спокойно
  оставлять в коде сайта, так задумано самим Firebase. Реальная защита
  данных — в правилах доступа (Шаг 4), а не в том, что конфиг скрыт.
- Оплата (Payme/Click) и заявки на оплату по-прежнему идут в Google
  Таблицу, как настроено раньше — это не меняется.
